# AI News Collector

A skill that searches the web for the latest AI news and compiles them into a well-structured markdown report.

## Workflow

### Step 1: Determine the search scope

By default, collect news from the **previous day** (yesterday). If the user specifies a different date range, use that instead.

Determine today's date using bash (`date`) and calculate the target date range.

### Step 2: Search for news

Use the WebSearch tool to run **4-5 targeted searches** covering different AI domains:

1. **LLM & Generative AI** — new model releases, benchmarks, product updates from OpenAI, Anthropic, Google, Meta, etc.
2. **AI Industry & Business** — funding rounds, acquisitions, partnerships, company news
3. **AI Research & Breakthroughs** — notable papers, new techniques, state-of-the-art results
4. **AI Policy & Regulation** — government policies, safety discussions, ethics debates
5. **AI Applications** — robotics, healthcare AI, autonomous vehicles, AI agents, enterprise AI

For each search, include the target date in the query to get recent results. Example: "AI news March 26 2026"

### Step 3: Filter and deduplicate

From all search results:
- Remove duplicate stories that appear across multiple searches
- Prioritize stories with high impact or broad relevance
- Aim for **8-15 news items** total
- Each item must have: title, source, URL, and a 2-3 sentence summary

### Step 4: Categorize and write the report

Organize news into these categories (skip empty categories):

```markdown
# AI Daily Briefing — {YYYY-MM-DD}

> Collected on {timestamp} via web search

## Highlights
<!-- 1-2 sentence overview of the day's biggest story -->

## LLM & Generative AI
### {Title}
**Source**: [{source name}]({url})
{2-3 sentence summary}

## AI Industry & Business
...

## AI Research & Breakthroughs
...

## AI Policy & Regulation
...

## AI Applications
...

---
*This report was generated by the AI News Collector skill.*
```

### Step 5: Save the report

Save the markdown file to the current working directory with the naming convention:
```
ai-news-{YYYY-MM-DD}.md
```

If the user specified a workspace or output directory, save there instead.

## Important Guidelines

- Always include the source URL for every news item — readers need to verify and read the full article
- Write summaries in Korean if the user's conversation is in Korean; otherwise default to English
- If a search returns no relevant results for a category, skip that category entirely rather than padding with weak content
- The "Highlights" section should call out the single most impactful story of the day
- Prefer authoritative sources (major tech publications, official company blogs, academic institutions)
- When the same story is covered by multiple sources, pick the one with the most detail
