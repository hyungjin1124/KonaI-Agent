### 보충 메모: OpenAI ChatKit (이전 리포트 UPDATE-1 generative_ui에 추가)

이전 리포트에서 generative_ui의 UPDATE를 A2UI/MCP Apps/AG-UI 3대 표준 중심으로 보고했으나,
OpenAI ChatKit은 이들과 **다른 접근법**을 제시:

- **프리빌트 임베더블 위젯**: 에이전트 빌더에서 설정 → 웹사이트/앱에 임베드
- **ChatKit JS/Python SDK**: 클라이언트-서버 양방향 이벤트 (`chatkit.tool.change`, `ClientEffectEvent`)
- **Rich Content Segments**: `setComposerValue()`가 텍스트 + 도구 선택 + 모델 선택 + 파일 첨부를 한번에 처리
- **브랜드 커스터마이징**: 테마, 아이콘, 시작 화면 프롬프트 커스텀
- **표준 API 가격 포함**: 별도 위젯 라이선스 없음

이 접근법은 KonaI-Agent의 "에이전트 채팅 임베딩" 시나리오에 참고할 수 있으며,
`/research generative_ui` 갱신 시 A2UI/MCP 표준과 함께 ChatKit 패턴도 포함 권장.

### 보충 메모: Open Responses Spec (프로토콜)

OpenAI가 발표한 **Open Responses**는 멀티 프로바이더 상호운용성을 위한 오픈소스 API 사양:

- **목적**: 프로바이더 독립적인 요청/응답 모델, 스트리밍 시맨틱, 도구 호출 패턴 표준화
- **지원**: HuggingFace, Vercel, Ollama, vLLM 등 지원
- **핵심 요소**: 에이전틱 루프, Items(원자적 컨텍스트 단위), 시맨틱 스트리밍 이벤트
- **사이트**: https://www.openresponses.org/
- **KonaI-Agent 관련**: 백엔드 아키텍처에서 멀티 모델 지원 시 참조. 직접적 UI 패턴은 아니므로 카탈로그 항목 추가는 불필요
