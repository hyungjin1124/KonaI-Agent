#### NEW-1: MCP Apps Renderer
- **발견 출처**: https://blog.modelcontextprotocol.io/posts/2026-01-26-mcp-apps/
- **경쟁사 현황**:
  - **Anthropic**: Claude 웹/데스크톱에서 MCP Apps 지원. Artifacts 내에서 MCP를 통해 외부 서비스(Slack, Canva, Figma 등) 연동 가능

  - **Microsoft**: M365 Copilot Chat에서 MCP 기반 에이전트에 rich UI 위젯 지원 (2026년 2월 말 Public Preview)
  - **VS Code**: Insiders에서 MCP Apps 지원
  - **Anthropic + OpenAI + MCP-UI**: 공식 MCP 확장 표준 공동 개발
- **기술 구현**: 도구 정의에 `ui://` 리소스 선언 → LLM이 도구 호출 → 호스트가 리소스 fetch → sandboxed iframe에 렌더링 → JSON-RPC over postMessage 양방향 통신
- **KonaI-Agent 관련성**: 엔터프라이즈 대시보드에서 외부 도구(데이터 분석, 차트, 폼 등)의 결과를 채팅 내에서 직접 인터랙션할 수 있음. 기존 artifact_panel과 결합하면 강력한 도구 통합 패턴 구현 가능

#### NEW-2: Agent Plan Mode
- **발견 출처**: https://openai.com/index/introducing-chatgpt-agent/, https://windsurf.com/changelog
- **경쟁사 현황**:
  - **ChatGPT**: Deep Research에서 연구 계획 생성 → 사용자가 중간에 편집/수정 가능. Agent Mode에서도 복잡한 작업 전 계획 단계 표시
  - **Cursor/Windsurf**: Cascade의 Plan Mode — Code/Ask 외에 별도 모드로 구현 계획 생성 후 실행
  - **GitHub Copilot**: Plan Mode에서 blueprint 리뷰/승인 후 Agent Mode가 실행
  - **OpenAI AgentKit**: Agent Builder에서 visual canvas로 워크플로우 계획
- **기존 컴포넌트와의 차이**: `multi_step_progress`는 실행 중 진행 표시에 초점. Plan Mode는 실행 전 계획 수립 → 사용자 리뷰/편집 → 승인 후 실행의 3단계 워크플로우
- **KonaI-Agent 관련성**: PPT 시나리오 등 멀티스텝 에이전트 작업에서 실행 전 계획을 사용자에게 보여주고 편집/승인받는 UX가 필수적. 현재 HITL은 단계별 승인만 가능하고, 전체 계획 조망/편집은 불가
- **권장 액션**: `/research agent-plan-mode`

#### NEW-3: Background Agent Manager
- **발견 출처**: https://medium.com/ai-software-engineer/cursor-2-0-has-arrived-and-agentic-ai-coding-just-got-wild-65bbbd3be4ec
- **경쟁사 현황**:
  - **Cursor 2.0**: 최대 8개 에이전트 동시 실행. 각 에이전트 격리 환경(Ubuntu VM). Slack/웹/모바일에서 시작 가능. 별도 브랜치에서 작업 후 PR 생성
  - **Claude Code Tasks**: 영속적 Task 시스템. DAG 기반 종속성 관리. 세션/머신 간 상태 복원. 서브에이전트 조율
  - **GitHub Copilot**: Coding Agent가 백그라운드에서 PR 생성. 새 Agents Tab에서 리포 단위 에이전트 관리
  - **OpenAI Codex**: macOS 앱에서 다수 코딩 에이전트 병렬 관리. 진행/결정 내역 확인, 클린 diff 리뷰
- **기존 컴포넌트와의 차이**: `parallel_execution_view`는 동시 실행 상태의 시각화에 초점. Background Agent Manager는 비동기 에이전트 생명주기(생성 → 모니터링 → 일시정지 → 취소 → 리뷰 → 결과 채택) 전체를 관리하는 UI
- **KonaI-Agent 관련성**: 엔터프라이즈 환경에서 여러 분석 에이전트가 백그라운드로 데이터 수집/분석을 수행하고 결과를 사용자에게 보고하는 패턴에 활용. 현재 PPT 시나리오의 asyncTool 패턴을 일반화
- **권장 액션**: `/research background-agent-manager`

#### NEW-4: Entity Knowledge Card
- **발견 출처**: https://help.openai.com/en/articles/6825453-chatgpt-release-notes
- **경쟁사 현황**:
  - **ChatGPT**: 일상 질문 응답에서 중요한 사람, 장소, 제품, 아이디어를 하이라이트. 탭하면 핵심 사실과 신뢰 출처가 포함된 사이드 패널이 열림. 후속 질문 없이 컨텍스트 파악 가능

  - **Claude**: 아직 유사 기능 없음
- **기존 컴포넌트와의 차이**: `citation_source_link`는 응답에 출처 링크 표시. Entity Knowledge Card는 응답 텍스트 내 엔티티를 자동 인식하여 인라인 하이라이트 + 상세 정보 패널 제공. 범위가 더 넓음 (출처뿐 아니라 관련 사실, 정의, 관계 등)
- **KonaI-Agent 관련성**: 매출 분석 응답에서 제품명, 지역, 거래처 등을 자동 하이라이트하고 탭하면 관련 KPI, 이력, 연관 데이터를 사이드패널에 표시하는 패턴. 기존 드릴다운과 시너지

#### NEW-5: Visual Dynamic Response
- **발견 출처**: https://gemini.google/release-notes/, https://blog.google/innovation-and-ai/products/google-ai-updates-january-2026/
- **경쟁사 현황**:
  - **Google Gemini**: Visual Layout & Dynamic View (Labs). 텍스트 너머 시각적으로 몰입적인 응답 — 사진, 인터랙티브 모듈 포함. 사용자 피드백을 수집하여 여러 턴에 걸쳐 커스터마이징
  - **ChatGPT**: at-a-glance visuals로 통계, 단위 변환, 계산 등 시각적 표시. 하이라이트 + 사이드패널
  - **Claude**: Artifacts가 유사하지만, 메인 응답 자체가 시각적이지는 않음
- **기존 컴포넌트와의 차이**: 현재 카탈로그의 응답 표시는 텍스트(마크다운) + 별도 아티팩트 패널. Visual Dynamic Response는 응답 자체가 텍스트/이미지/인터랙티브 모듈이 혼합된 리치 레이아웃. A2UI 프로토콜과 직결
- **KonaI-Agent 관련성**: 매출 분석 응답에서 텍스트 설명과 미니 차트, KPI 카드, 인터랙티브 필터가 하나의 응답 내에 통합 표시. 현재 별도 위젯에서만 가능한 시각화를 채팅 응답에 인라인으로 삽입
- **권장 액션**: `/research visual-dynamic-response`
