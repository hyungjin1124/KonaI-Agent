### 상세

#### NEW-1: Agent-UI Event Protocol (선언적 에이전트 UI)

- **발견 출처**: [AG-UI Protocol](https://docs.ag-ui.com/), [Google A2UI](https://developers.googleblog.com/introducing-a2ui-an-open-project-for-agent-driven-interfaces/), [CopilotKit MCP Apps + AG-UI](https://www.copilotkit.ai/blog/bring-mcp-apps-into-your-own-app-with-copilotkit-and-ag-ui)
- **경쟁사 현황**:
  - **AG-UI Protocol**: 이벤트 기반 경량 프로토콜. 에이전트 상태, UI 인텐트, 사용자 인터랙션을 프런트엔드와 양방향 스트리밍. AG2가 2월에 네이티브 지원 발표. CopilotKit이 `MCPAppsMiddleware`로 MCP Apps 서버의 인터랙티브 UI를 인앱 렌더링 지원.
  - **Google A2UI (v0.8 Public Preview)**: 선언적 JSON 기반 프로토콜. 클라이언트가 신뢰 컴포넌트 카탈로그(Card, Button, TextField 등)를 관리하고, 에이전트는 해당 타입만 참조 가능. "안전한 Generative UI" 접근.
  - **Microsoft AG-UI HITL 통합**: AG-UI 위에서 HITL 이벤트 흐름을 표준화하는 공식 가이드 제공.
- **KonaI-Agent 관련성**: 카탈로그의 `generative_ui`(research_needed)와 직접 연관. 현재 시나리오 오케스트레이션이 커스텀 이벤트 기반이므로, 표준 프로토콜 채택 시 에이전트↔프런트엔드 통신을 표준화할 수 있음. Google A2UI의 "신뢰 컴포넌트 카탈로그" 접근은 Artifact Panel에서 에이전트가 안전하게 UI를 생성하는 패턴으로 참고 가능.
- **confidence**: medium (AG-UI + Google A2UI + CopilotKit 3개 프로젝트에서 추진 중이나, 아직 GA 전 단계)
