#### APPROVE-1: artifact_panel
- **판정 근거**: Artifact Panel은 에이전트 채팅의 핵심 UX 패턴으로, ChatGPT Canvas와 Claude Artifacts가 업계 표준으로 확립했다. document_viewer가 구현 완료된 상태에서 이를 담는 Artifact Panel 자체의 완성도를 높이는 것이 자연스러운 다음 단계다. MCP 연동과 직접 편집까지 가지 않더라도, 현재 ArtifactPreviewPanel의 레이아웃/인터랙션을 개선하면 높은 가시적 가치를 얻을 수 있다.
- **권장 리서치 범위**: Canvas/Artifacts 레이아웃 패턴, 탭/히스토리 관리, 패널 리사이즈/분리, document_viewer와의 통합 개선
- **예상 complexity**: moderate

#### APPROVE-2: agent_plan_mode
- **판정 근거**: Cursor, Windsurf, GitHub Copilot, ChatGPT Deep Research 모두 Plan Mode를 도입했으며, 복잡한 에이전트 작업 전 계획을 사용자에게 보여주고 편집/승인받는 것이 업계 표준이 되었다. 현재 PPT 시나리오의 단계별 HITL만으로는 전체 계획 조망이 불가하며, 엔터프라이즈 환경에서 "실행 전 계획 확인"은 거버넌스 필수 요소다.
- **권장 리서치 범위**: 계획 표시 UI, 편집 인터랙션, 승인 후 실행 전환, 진행 중 계획 변경 패턴
- **예상 complexity**: moderate

#### APPROVE-3: approval_rejection
- **판정 근거**: 현재 PPT 시나리오 훅에 결합된 승인/거절 로직을 범용 ApprovalGate 컴포넌트로 분리하는 것은 이미 카탈로그에서 지적한 기술 부채다. 업계에서 Risk-tiered HITL과 협상형 다이얼로그로 진화하고 있어, 리서치를 갱신하고 범용 컴포넌트를 설계해야 한다.
- **권장 리서치 범위**: Risk-tiered 승인 등급, 협상형 수정-재제안 루프, 정책 기반 자동 분류, 엔터프라이즈 감사 추적
- **예상 complexity**: moderate

#### APPROVE-4: multi_step_progress
- **판정 근거**: Plan Mode와 밀접하게 연관되며, "계획 → 실행 → 진행 표시 → 결과 리뷰" 전체 라이프사이클을 아우르는 컴포넌트로 발전시켜야 한다. 현재 partial 상태이므로 기존 구현 위에 쌓기 좋다.
- **권장 리서치 범위**: Plan → Execute → Progress → Review 통합 UI, 기존 usePPTScenario 훅과의 관계 정리
- **예상 complexity**: moderate

#### APPROVE-5: entity_knowledge_card
- **판정 근거**: 매출 분석 응답에서 제품명/지역/거래처 등을 자동 하이라이트하고 상세 정보를 사이드패널에 표시하는 패턴은 엔터프라이즈 대시보드에 직접 적용 가능하다. 다만 citation_source_link가 최근 구현되었으므로 이를 안정화한 후 확장하는 것이 적절하다.
- **권장 리서치 범위**: 엔티티 인식 패턴, 사이드패널 구조, 기존 drill_down과의 시너지
- **예상 complexity**: moderate
