#### DEFER-1: Agent Dispatch (비동기 위임)

- **적합성**: RELEVANT — 에이전트 자율 실행 + 결과 큐잉은 엔터프라이즈 시나리오에서 중요한 방향. 현재 `isAsyncTool` 패턴과 개념적 유사성
- **호환성**: ADAPTABLE — 비동기 실행 큐잉, 모니터링 대시보드, 자율성 레벨 설정 UI 등 별도 인프라 계층 필요
- **ROI**: MEDIUM — 차별화 가치 높으나 complexity complex. 투자 대비 불확실성
- **의존성**: PARTIAL — scheduled_agent_tasks(PASS), usage_monitoring(PASS) 기반이나 백엔드 큐잉 인프라 필요
- **타이밍**: WAIT — Claude Dispatch, Cursor Self-hosted Agents, GitHub Agent 세션 로그 등 3개 제품이 동시에 발전 중이나 UX 패턴이 아직 수렴하지 않음. 1~2회 추가 스캔 후 패턴 안정화 확인
- **판정 근거**: 비동기 위임은 에이전트 UI의 다음 진화 방향이나, "사용자 부재 중 자율 실행 + 감독 대시보드" 패턴이 제품마다 크게 다르다. Claude는 화면 녹화 기반, Cursor는 클라우드 샌드박스 기반, GitHub는 PR 코멘트 기반으로 접근이 상이하다. 패턴이 수렴할 때까지 대기하면서 추적한다.
