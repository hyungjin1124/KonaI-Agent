#### APPROVE-1: nl_to_chart
- **판정 근거**: 5회 연속 리포트에서 권장되었으며, Databricks(Genie Research + Inspect Mode + Chart Faceting), Power BI(Conversational App Copilot + 앱 자동 선택), ThoughtSpot(Data Prep Agent) 3개 주요 제품에서 NL→시각화 패턴이 동시에 강화되고 있다. KonaI-Agent의 핵심 시나리오인 에이전트 기반 데이터 분석과 직결되며, Liveboard 위젯 생성 자동화의 기반이 된다. not_implemented 상태로 리서치가 시급하다.
- **권장 리서치 범위**: Databricks Genie Research의 "질문→계획→다중쿼리→반복추론→답변" 파이프라인 아키텍처, Inspect Mode의 자동 SQL 검증 패턴, Power BI의 기존 대시보드 NL 탐색 패턴. 차트 생성 vs 대시보드 탐색 두 가지 접근법의 트레이드오프 분석.
- **예상 complexity**: complex

#### APPROVE-2: chat_input
- **판정 근거**: 5회 연속 리포트에서 권장되었으며 현재 partial 상태다. 멀티모달 입력(파일, 이미지, 음성)은 에이전트 대시보드의 기본 인터랙션 품질을 좌우하는 핵심 컴포넌트다. Telerik의 AI-ready Chat 입력 모드 전환 + prefix/suffix 패턴이 참조할 만한 모델을 제시한다. markdown_renderer 완료 후 대화 인터페이스 품질 개선의 자연스러운 다음 단계.
- **권장 리서치 범위**: 입력 모드 전환 패턴(텍스트/파일/이미지), prefix/suffix 커스터마이징, 멀티모달 첨부 UX, 입력 자동완성/제안.
- **예상 complexity**: moderate
