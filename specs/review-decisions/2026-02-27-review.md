#### APPROVE-1: agent_self_review (Agent Self-Review / Auto-Validation)

- **판정 근거**: GitHub Copilot, Cursor, Apple Xcode 3개 제품이 같은 날(Feb 26) 동시에 "에이전트 자체 검증" 패턴을 발표하여 confidence가 매우 높다. KonaI-Agent의 시나리오 워크플로우(PPT 생성, 분석)에서 에이전트 산출물을 사용자에게 제시하기 전 자체 검증하는 품질 게이트는 기존 `approval_rejection`과 조합하여 "에이전트 자체검증 → 사용자 최종승인"의 2단계 품질 관리를 구현할 수 있다. 구현 복잡도는 moderate이나, UI 패턴 자체는 기존 tool_call_display와 approval_rejection 패턴을 확장하여 구현 가능하므로 ROI가 높다.
- **권장 리서치 범위**: (1) GitHub Copilot Self-review + Cursor Bugbot Autofix의 자동 검증-수정 루프 UX, (2) Xcode의 마일스톤/롤백 지점 생성 패턴, (3) 기존 approval_rejection과의 통합 아키텍처 (pre-approval validation layer), (4) 검증 결과 시각화 (pass/fail/warning 상태)
- **예상 complexity**: moderate (3-5일)

#### APPROVE-2: parallel_execution_view (UPDATE — 범위 확장)

- **권장 리서치 범위**: (1) 에이전트 세션 상태 모델 (시작/실행 중/일시정지/완료/핸드오프), (2) CLI Handoff 패턴의 웹 UI 적용, (3) 서브에이전트 분기·병합 시각화
