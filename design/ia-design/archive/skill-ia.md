# 스킬 메뉴 정보 구조 설계 (Skill IA)

**작성 일자**: 2026-03-21
**근거**: `/design/research/03-skill.md` (벤치마크 분석)
**대상 플랫폼**: KonaI-Agent v1.0 프로토타입
**제품 포지셔닝**: 엔터프라이즈 AI 에이전트 플랫폼 (다중팀 협업)

---

## 1. 메뉴 목적

**스킬 메뉴는 전사 직원이 재사용 가능한 업무 자동화 도구를 검색, 생성, 관리, 공유하는 중앙 허브이다.**

조직 내 스킬(AI 에이전트가 호출 가능한 업무 자동화 도구)의 생명주기 전체를 지원하며, 개인 스킬에서 조직 스킬로 확대 가능한 거버넌스 기반을 제공한다.

---

## 2. 하위 구조: 탭/섹션 구성

### 2-1. 최상위 레이아웃: 통합 vs 분리

**결정**: **내 스킬(Personal)과 탐색(Discover) 분리 + 통합 관리(Admin)**

**근거**:
- Claude Code: 개인(로컬) vs 공식 vs 커뮤니티 3계층 분리 → 사용자 혼동 없음
- ChatGPT: "My GPTs" 탭과 "GPT Store" 완전 분리 → 사용자 심리 명확 (소유권 vs 탐색)
- Dify: Tools(인증), Plugins(설치), Studio(사용) 3곳 분리 → 엔터프라이즈 복잡성
- Coze: 워크스페이스 리소스 vs 스토어 분리, 에이전트 빌더 내부 추가 UI → 3곳 접근 가능

**KonaI 적용 구조**:

```
상단 네비게이션: 홈/대시보드 | AI 채팅 | 스킬 | 데이터 | 관리자
                                  │
                          ┌─────────┼─────────┐
                    내 스킬(Tab A)    탐색(Tab B)   관리(Tab C)
                                              └─ 관리자만
```

**세 탭의 구성**:

| 탭 | 대상 사용자 | 기능 | 주요 액션 |
|----|-----------|------|----------|
| **내 스킬** | 모든 직원 | 개인이 생성한 + 설치한 스킬 목록 | 사용, 편집, 삭제, 팀 공유 |
| **탐색** | 모든 직원 | 조직 내 공개 스킬 + 추천 | 검색, 필터, 설치, 세부 보기 |
| **관리** | 스킬 관리자 | 전사 스킬 거버넌스, 권한, 모니터링 | 승인, 비활성화, 권한 관리, 통계 |

---

### 2-2. 각 탭의 상세 구성

#### **탭 A: 내 스킬 (Personal Skills)**

목적: 사용자 개인이 생성하거나 설치한 스킬을 관리하는 대시보드

**화면 구조**:

```
┌─────────────────────────────────────────┐
│  내 스킬                  [+ 새 스킬 만들기]│
├─────────────────────────────────────────┤
│ 필터/정렬: 최근 수정 | 이름순 | 사용 빈도 │
├─────────────────────────────────────────┤
│ 검색 바: "마케팅 스킬 검색..." 🔍        │
├─────────────────────────────────────────┤
│                                         │
│  [카드 레이아웃 또는 컴팩트 리스트]      │
│  스킬1 | 스킬2 | 스킬3 | ... (페이지네이션)│
│                                         │
│  스킬카드 콘텐츠:                        │
│  ┌─────────────────────────────┐       │
│  │ 스킬 아이콘  스킬명          │       │
│  │ 설명 (2줄)                 │       │
│  │ 👤 1.2K 사용 | 👥 5명 공유  │       │
│  │ [더보기▼] [편집] [공유]      │       │
│  └─────────────────────────────┘       │
│                                         │
└─────────────────────────────────────────┘
```

**콘텐츠 표시 우선순위**:
1. 최근 생성/편집 스킬 (Hot)
2. 자주 사용하는 스킬 (Frequency)
3. 최근 다른 사람이 공유한 스킬 (Shared)
4. 전체 개인 스킬 목록 (paginated)

**주요 상호작용**:
- **[+ 새 스킬 만들기]**: 스킬 생성 마법사로 이동
- **검색/필터**: 스킬 이름, 설명, 카테고리, 태그로 검색
- **스킬 카드 클릭**: 스킬 상세 화면 열기 (아래 2-3 참조)
- **[더보기▼]**: 드롭다운 메뉴 - 편집, 삭제, 이름 변경, 이 버전 복사, 버전 이력 보기
- **[공유]**: 팀/워크스페이스로 공유 확인 → "탐색" 탭에서 다른 사용자가 볼 수 있음

---

#### **탭 B: 탐색 (Discover/Marketplace)**

목적: 조직 내 공개된 스킬을 발견하고 설치하는 허브

**화면 구조**:

```
┌─────────────────────────────────────────┐
│  스킬 탐색                    [필터▼] [정렬▼] │
├─────────────────────────────────────────┤
│ 검색 바: "사내 공개 스킬 검색..." 🔍        │
├─────────────────────────────────────────┤
│ 필터:                                    │
│  ☑ 카테고리: 인사 | 재무 | 마케팅 | 기술  │
│  ☑ 상태: 공개 | 팀 전용 | 최신 추가      │
│  ☑ 정렬: 인기순 | 최신순 | 별점순        │
├─────────────────────────────────────────┤
│                                         │
│  📌 추천 스킬 섹션 (상단)                 │
│  "이 스킬들이 인기예요" (Carousel)       │
│  ┌──────┐  ┌──────┐  ┌──────┐         │
│  │스킬1 │  │스킬2 │  │스킬3 │...      │
│  └──────┘  └──────┘  └──────┘         │
│                                         │
│  🔥 전사 추천                            │
│  스킬A | 스킬B | 스킬C | ...             │
│                                         │
│  ↓ 모든 스킬 (그리드 또는 리스트)          │
│  스킬1 카드 | 스킬2 카드 | ...            │
│                                         │
│  스킬 카드 콘텐츠:                        │
│  ┌───────────────────────────────┐    │
│  │ 스킬 아이콘  스킬명            │    │
│  │ 설명 (2줄)                   │    │
│  │ ⭐ 4.5 (12 평가) | 👥 3.2K 사용 │    │
│  │ 게시자: 팀명 | 공개                │    │
│  │ [자세히] [설치] 또는 [이미 설치됨]   │    │
│  └───────────────────────────────┘    │
│                                         │
└─────────────────────────────────────────┘
```

**콘텐츠 구성**:

1. **추천 섹션** (Carousel): 이전 주 인기 스킬, 신규 공개 스킬
2. **모든 스킬 그리드**: 카드 기반 (그리드 또는 리스트 선택 가능)
3. **각 카드에 포함될 정보**:
   - 스킬 이름 + 간단한 아이콘
   - 설명 (최대 100자)
   - 별점 (5점) + 평가 수
   - 사용자 수 (누적)
   - 게시자 정보 (팀명 또는 개인명)
   - 공개 범위 아이콘 (🔓 공개 / 🔒 팀 전용)
   - CTA 버튼: [자세히] / [설치]

**주요 상호작용**:
- **검색**: 스킬 이름, 설명, 게시자로 전문 검색
- **필터**: 카테고리, 상태(공개/팀전용), 정렬(인기/최신/평점)
- **스킬 카드 클릭**: 스킬 상세 화면 (아래 2-3 참조)
- **[설치]**: 스킬을 "내 스킬" 탭에 추가 (구독 모델)
- **[자세히]**: 풀 스크린 세부 보기 (평가, 리뷰, 버전 이력, 사용 통계)

---

#### **탭 C: 관리 (Admin - 스킬 관리자만 가시)**

목적: 전사 스킬 거버넌스 및 모니터링

**가시 조건**:
- 사용자 권한이 "스킬 관리자" 또는 상위 (예: 관리자 페이지에서 설정)
- 없으면 탭이 숨겨짐

**화면 구조**:

```
┌──────────────────────────────────────────┐
│  스킬 관리                                  │
├──────────────────────────────────────────┤
│ 필터/검색: 게시자 | 상태 | 마지막 수정 | 사용량│
├──────────────────────────────────────────┤
│                                          │
│ 테이블 뷰:                                 │
│ ┌──────────────────────────────────────┐│
│ │스킬명 │게시자 │상태│평가│사용수│마지막수정││
│ ├──────────────────────────────────────┤│
│ │ 스킬A │팀A  │승인│4.8│1.2K │2026-03-20││
│ │ 스킬B │팀B  │검토│3.2│450  │2026-03-19││
│ │ 스킬C │개인A│비활성│2.1│-  │2026-02-28││
│ │ ... 더보기                            ││
│ └──────────────────────────────────────┘│
│                                          │
│ [스킬 상세 → 상태 변경/편집 가능]          │
│  - 승인 대기 → [승인] [거부]             │
│  - 활성 → [비활성화]                    │
│  - 권한 설정 (공개/팀전용)               │
│  - 별점 리뷰 관리 (불건전 리뷰 삭제)      │
│                                          │
└──────────────────────────────────────────┘
```

**관리자 기능**:
- 모든 스킬 목록 (공개 상태 무관)
- 스킬 상태: 승인 대기 / 활성 / 비활성
- 스킬 편집 권한 (게시자만 또는 관리자도)
- 부적절한 리뷰/평가 관리
- 스킬 사용 통계 (일별/주별/월별)
- 게시자별 통계 분석

**관리자 탭은 별도 상세 섹션(2-4)에서 다룸**.

### 2-3. 스킬 상세 화면 (Detail View)

**진입 경로**:
- "내 스킬" 탭 → 스킬 카드 클릭
- "탐색" 탭 → 스킬 카드 클릭
- AI 채팅에서 스킬 사용 후 → 스킬 피드백 링크 클릭

2. **메타데이터**: 평점, 사용자 수, 마지막 업데이트, 생성일
3. **탭 1 (개요)**: 마크다운 렌더링된 설명, 주요 기능, 권한, 제약사항, 카테고리, 태그
4. **탭 2 (사용 방법)**: 설정 가이드, 채팅 프롬프트 예제, API 문서 (개발자용)
5. **탭 3 (평가)**: 평점 분포, 사용자 리뷰, 리뷰 작성 폼
6. **탭 4 (버전)**: 버전 이력, 변경 사항, 롤백 옵션
7. **푸터**: [설치]/[이미 설치됨], [피드백], [신고]

**오른쪽 패널 옵션 ([옵션▼])**:
- 내가 생성한 스킬인 경우: [편집], [삭제], [이름 변경], [공개 범위 변경]

### 2-4. 스킬 생성/편집 화면

**진입 경로**:
- "내 스킬" 탭 → [+ 새 스킬 만들기]
- "내 스킬" 탭 → 기존 스킬 카드 → [더보기] → [편집]

**화면 구조** (마법사 방식 또는 한 페이지):

```
┌────────────────────────────────────────────────┐
│  새 스킬 만들기                 [임시 저장] [취소]│
│  ─────────────────────────────────────────────│
│  Step 1: 기본 정보  → Step 2: 상세설명 → Step 3: 게시│
│  ═════ (진행 중)                               │
├────────────────────────────────────────────────┤
│                                                │
│  Step 1: 기본 정보                              │
│  ───────────────────────────────────────────  │
│                                                │
│  스킬 이름: [입력 필드: "계약서 자동 검토"]      │
│  아이콘: [프리셋 6개 또는 업로드]                │
│  카테고리: [드롭다운: 인사/재무/마케팅/기술/기타]│
│  태그: [멀티셀렉트: 보험, 급여, 자동화, ...]   │
│                                                │
│  한 줄 설명: [입력 필드]                        │
│  (마켓플레이스에서 보여질 짧은 설명)           │
│                                                │

## 4. 다른 메뉴와의 연결점

### 4-1. 스킬 ↔ AI 채팅

**채팅에서 스킬 호출 방식**:

```
사용자 입력 (채팅):
"이 계약서 검토해줄 수 있어?"

AI 응답 (백엔드):
1. 사용자의 활성 스킬 목록 확인
2. "계약서 자동 검토" 스킬이 설치되어 있음 인식
3. 스킬 메타데이터 로드 (이름, 설명, 입력/출력)
4. LLM 추론으로 스킬 자동 호출 (또는 사용자 확인)
5. 스킬 실행 → 결과 반환 → 사용자에게 표시

UI에서의 표시:
┌─────────────────────────────┐
│ Claude: "계약서를 검토하겠습니다." │
│ [스킬 실행 중...] ⏳           │
│                             │
│ [🎯 계약서 자동 검토 사용]     │
│ 결과 표시...                 │
│                             │
│ [이 스킬 더 알아보기] 링크    │
│ [피드백] [이 버전 사용]        │
└─────────────────────────────┘
```

**채팅에서 스킬 명시적 선택**:

```
사용자 입력 (채팅):
"@계약서 검토" 또는 "/" 명령어

드롭다운 검색:
┌──────────────────────┐
│ / 명령 또는 스킬 검색  │
│ [검색 입력...]       │
├──────────────────────┤
│ 계약서 자동 검토     │
│ 계약서 조회         │
│ 계약서 생성         │
│ ...                 │
└──────────────────────┘
```

**채팅 결과에서 스킬 피드백**:

```

│ - 결과가 불완전함                      │

└─────────────────────────────────────────┘
```

**백엔드 연결 (세부)**:

| 항목 | 설정 | 설명 |
|------|------|------|
| 스킬 등록 | 자동 | "내 스킬" 또는 "탐색"에서 설치한 모든 스킬은 사용자의 활성 스킬 목록에 추가 |
| 호출 정책 | 자동 또는 확인 | AI가 자동으로 호출할지, 사용자 승인 후 호출할지 설정 (스킬 설정 시 선택 가능) |
| 컨텍스트 전달 | 자동 | 스킬에 필요한 입력 파라미터를 채팅 컨텍스트에서 자동 추출 |
| 오류 처리 | 스킬 정책 | 스킬 실행 실패 시 재시도, 폴백, 사용자 알림 설정 |

### 4-4. 스킬 → 데이터 메뉴

**스킬이 데이터에 접근하는 방식**:

```
시나리오: 스킬이 "직원 정보" 테이블에 접근해야 함

Step 1. 스킬 생성 시 권한 선언:
  "이 스킬은 '직원 정보' 데이터에 읽기 권한이 필요합니다"
  → 스킬 상세 화면에 표시

Step 2. 사용자가 스킬 설치 시:
  권한 확인 다이얼로그에 표시:
  "이 스킬은 다음에 접근합니다:"
  "- 직원 정보 (읽기)"

  사용자가 승인 → 스킬이 설치되고 데이터 접근 활성화

Step 3. 스킬 실행 시:
  - 스킬 런타임이 데이터 메뉴의 테이블을 쿼리
  - 사용자의 권한(역할 기반)에 따라 필터링된 데이터만 반환
  - 스킬 실행 로그에 어떤 데이터에 접근했는지 기록
```

**스킬과 데이터의 접근 제어 통합**:

| 주체 | 권한 설정 | 설명 |
|------|----------|------|
| 스킬 | 필요 권한 선언 | "직원 정보 읽기", "급여 쓰기" 등 |
| 사용자 | 스킬 사용 권한 | 이 스킬을 사용할 수 있는가? (역할 기반) |
| 데이터 | 테이블 접근 제어 | 이 사용자/스킬이 이 테이블에 접근할 수 있는가? |
| 교집합 | 최소 권한 원칙 | 스킬 + 사용자 + 데이터 3가지 모두 만족해야 실행 가능 |

---

### 4-5. 스킬 ↔ 관리자 메뉴

**스킬 권한 관리 (관리자 페이지)**:

관리자 메뉴의 "스킬 관리" 섹션:

```
관리자 → 스킬 관리 탭
┌──────────────────────────────────────┐
│ 스킬 거버넌스                          │
├──────────────────────────────────────┤
│                                      │
│ 승인 대기 스킬: 3개                   │
│ [검토하기] → 스킬 메뉴의 관리 탭으로 │
│                                      │
│ 전사 공개 스킬 정책:                 │
│ ◉ 누구나 게시 가능                   │
│ ○ 관리자 승인 후 게시                │
│ ○ 특정 팀만 게시 가능                │
│                                      │
│ 스킬 사용 통계:                      │
│ - 전사 스킬 개수: 47개               │
│ - 지난 달 사용: 1,234회              │
│ - 평균 평점: 4.2/5                   │
│                                      │
│ [전체 통계 보기] → 스킬 메뉴 관리 탭│
│                                      │
└──────────────────────────────────────┘
```

**스킬 승인 워크플로우**:

```
공개 스킬 게시 요청 (사용자)
  ↓
스킬 메뉴 → 관리 탭 (관리자 확인)
  ↓
관리자 검토:
- 스킬 설명이 정확한가?
- 권한 선언이 명확한가?
- 부적절한 내용은 없는가?
  ↓
[승인] 또는 [거부 + 피드백]
  ↓
승인 시: "탐색" 탭에서 모든 사용자가 볼 수 있음
거부 시: 사용자에게 피드백 + 수정 후 재제출 가능
```

## 5. 역할별 차이

### 5-1. 일반 직원 (스킬 사용자)

**접근 가능한 탭**:
- "내 스킬": 자신의 스킬 목록 (생성/설치한 것들)
- "탐색": 공개/팀 스킬 발견
- "관리": 불가 (숨겨짐)

**가능한 액션**:

| 기능 | 권한 |
|------|------|
| 스킬 설치/제거 | ✅ |
| 스킬 생성 (개인용) | ✅ |
| 스킬 생성 (팀 전용) | ✅ (자신의 팀만) |
| 스킬 공개 요청 | ✅ (관리자 승인 필요) |
| 스킬 편집 | ✅ (자신이 생성한 것만) |
| 스킬 삭제 | ✅ (자신이 생성한 것만) |
| 다른 스킬 평가 | ✅ |
| 다른 스킬 편집 | ❌ |
| 스킬 승인/거부 | ❌ |

---

### 5-2. 팀 리더/스킬 관리자 (선택적)

**접근 가능한 탭**:
- "내 스킬": 자신의 스킬
- "탐색": 공개/팀 스킬
- "관리": ✅ (팀 스킬만 또는 전사 스킬)

**가능한 액션** (팀 관리자):

| 기능 | 권한 |
|------|------|
| 팀 멤버 생성 스킬 검토 | ✅ |
| 팀 스킬 상태 변경 (활성/비활성) | ✅ |
| 부적절한 리뷰 삭제 | ✅ (팀 스킬) |
| 팀 스킬 권한 변경 | ✅ |
| 전사 스킬 승인 | ❌ (전사 관리자만) |

---

### 5-3. 관리자 (System Admin)

**접근 가능한 탭**:
- "내 스킬": 자신의 스킬
- "탐색": 모든 스킬
- "관리": ✅ (모든 스킬)

**가능한 액션**:

| 기능 | 권한 |
|------|------|
| 모든 스킬 조회 | ✅ |
| 스킬 상태 변경 | ✅ |
| 스킬 강제 비활성화 | ✅ |
| 부적절한 리뷰/평가 삭제 | ✅ |
| 스킬 게시 정책 설정 | ✅ |
| 스킬 사용 통계 조회 | ✅ |
| 게시자 제재 | ✅ (정책에 따라) |

```

    ↓
  AI 채팅에서 자동 호출 또는 명시 호출
    ↓
  피드백/평가 (선택)

기숙 사용자 (개인 스킬 생성):
  스킬 메뉴 → "내 스킬" 탭
    ↓
  [+ 새 스킬 만들기]
    ↓
  마법사 완료 (3단계)
    ↓
  스킬 상세 페이지 (초안)
    ↓
  팀과 공유 또는 공개 요청
    ↓
  관리자 승인 (공개인 경우)

## 8. 주요 설계 결정 근거

| 결정 | 근거 | 대안 |
|------|------|------|
| "내 스킬" vs "탐색" 분리 | ChatGPT, Coze, Dify 모두 분리 → 사용자 심리 명확 | 통합 UI (발견성 ↓) |
| 카드 기반 목록 UI | 마켓플레이스 표준 (ChatGPT, Coze, Dify) | 리스트만 (컴팩트하지만 발견성 ↓) |
| 3단계 생성 마법사 | ChatGPT GPT Builder 패턴 (사용성 ↑) | 한 페이지 양식 (로드 ↑) |
| 평가/리뷰 시스템 | ChatGPT GPT Store 참고 (신뢰도 ↑) | 평가 없음 (확인 ↓) |
| 권한 선언식 | Claude Code SKILL.md 패턴 | 동적 요청 (복잡) |
| 버전 관리 | 모든 벤치마크에서 지원 (안정성 ↑) | 버전 없음 (리스크 ↑) |
