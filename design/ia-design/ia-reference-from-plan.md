## 3.2 AI 채팅

- 새 대화 시작 버튼

## 3.3 스킬

> **IA 설계 문서로 이관됨**: `design/ia-design/03-skill-ia.md`
> 이 섹션은 IA 설계 과정에서 상세화되었으므로, 아래는 핵심 변경 사항만 기록한다.

### 주요 변경 (v4 IA 설계 반영)
- 스코프: 3단계(개인→팀→조직) → 2단계(내 스킬/공유) → **팀 기반 강제 공유**로 변경. 개인 스킬 영역 제거, 생성 즉시 팀 전체 공유 + **"미검토" 뱃지** 부착 + 관리자 알림 (사전 승인 없이 사후 검토)
- **활성화 모델**: 팀 스킬을 사본 없이 원본 참조. 내가 사용할 스킬만 활성화 토글로 선택
- **개인 수정본**: 편집 시작 시 자동 생성 (포크 버튼 없음). 편집 → **저장 → 편집 모드 종료 → 수정본 읽기 전용 뷰로 복귀**. 복귀 후 [편집]/[테스트]/[개선 제안 제출] 선택. 패널은 항상 "내 현재 버전" 표시 (수정본 없으면 원본, 있으면 수정본)
- **개선 제안 워크플로우**: 수정본 → 테스트 → 제안 → **원본 작성자에게 알림 (코멘트 기회)** → 관리자 **승인**(원본 병합, 새 버전) / **반려**(코멘트 필수, 수정 후 재제안 가능) → **결과: 제안자 + 원본 작성자에게 알림**
- 화면 구조: 마스터-디테일 → **테이블 + 슬라이드 패널**. 단일 테이블(활성화/비활성화 그룹) + 행 클릭 시 우측 패널. 패널 전체 확장 옵션
- **관리자 뷰**: 스킬 메뉴 내부 탭 (관리자에게만 표시). **통합 대기열** (유형 컬럼: 신규/제안/폐기, 유형 필터), 전체 스킬 관리, 카테고리 관리. [검토] 클릭 시 유형별 상세 패널 연동 (신규=전체 내용, 제안=diff 뷰, 폐기=내용+사용량)
- 스킬 허브 제거 (팀 범위만 보므로 별도 마켓 불필요)
- 스킬 추가 경로: 채팅 생성, 외부 파일 가져오기 (2가지). 허브 추가 경로 제거
- **삭제 권한**: 사용량 기반 — 다른 팀원 미사용 시 자유 삭제, 사용 중이면 폐기 요청 → 관리자 승인
- 아이콘 제거, 테이블 컬럼 (이름, 설명, 카테고리, 작성자, 수정일, 버전, 사용 횟수, 활성화 토글)
- **파일 탐색기 + 콘텐츠 뷰**: 스킬을 파일 패키지로 취급. 파일 목록(상단)에서 선택 → 콘텐츠 영역에 해당 파일 내용 표시. SKILL.md 기본 선택. 탭/스크롤 없이 파일 간 클릭 전환. 버전 이력·제안 이력은 콘텐츠 영역 아래 접힘 상태로 배치
- **패널 전체 편집 모드**: [편집] 클릭 시 패널 전체가 편집 모드로 전환. 파일 목록에서 파일 전환 시에도 편집 상태 유지, 각 파일 편집 상태 독립 관리. 텍스트(.md, .txt, .csv)는 인라인 편집, 스크립트(.py, .js, .sh)는 [채팅에서 수정], 바이너리는 [파일 교체]
- **테스트 시 자동 저장**: 미저장 변경이 있는 상태에서 [테스트] 클릭 시 자동 저장 후 테스트 실행
- 카테고리: 데이터 분석, 문서 생성, 업무 자동화, 커뮤니케이션 (관리자가 추가 가능)
- **버전 이력** + **제안 이력** 섹션

## 3.4 데이터

> 구조 변경: 기존 "데이터 소스" 탭이 파이프라인에 흡수됨. 현재 단일 소스(영림원 ERP).

### 데이터 파이프라인 화면 구성 참고
- 소스 연결: 파이프라인 DAG의 첫 번째 노드로 소스 추가·설정 (현재 영림원 ERP 단일)
- 파이프라인 시각 에디터: DAG 기반 노드·엣지 편집 (Databricks Workflows, n8n)
- 데이터 흐름 정의: 소스 → 변환 → 뷰 테이블
- 실행 상태 및 이력
- 연결 테스트: 소스 노드 설정 시 연결 검증 (Snowflake, Databricks Connection Test)

### 데이터 카탈로그 화면 구성 참고
- 테이블·뷰 통합 탐색: 파이프라인 결과물인 뷰 테이블 포함 (Snowflake Database Explorer, Databricks Unity Catalog)
- 테이블/컬럼 검색: Cmd+K 스타일 빠른 검색 (Snowflake, Databricks Catalog Explorer)
- 테이블 상세: 컬럼 정의, 데이터 타입, 설명
- 뷰 테이블 스키마: ERP → 뷰 테이블 매핑 확인
- 데이터 계보(Lineage): 그래프 시각화 (Snowflake, Databricks)

### 접근 제어 화면 구성 참고
- Layer 1: 역할별 허용 테이블 설정
- Layer 2: 부서, 사업영역, 법인별 필터 조건
- Layer 3: 고/중/저 민감도 분류

## 3.5 관리자

### 사용자 및 권한 화면 구성 참고
- 멤버 관리: 초대, 비활성화, 역할 변경
- 역할 정의: 기본 역할 (일반 직원, 데이터 담당자, 관리자) + Custom Role
- 그룹 관리: 부서/팀 단위
- SSO 설정: SAML SSO

### 모니터링 화면 구성 참고
- 사용량 분석: API 호출, 토큰 소비, 모델별 사용량
- 감사 로그: 누가 언제 무엇을 했는가
- 활동 리포트: 기간별 요약

### 시스템 설정 화면 구성 참고
- 조직 정보: 회사명, 로고, 도메인 등 기본 프로필 (독립 기능이 아닌 설정 화면 내 필드)
- 모델 프로바이더 설정: 사용 가능 모델, API 키
- 보안 정책: IP 화이트리스트, 세션 만료

### 플랫폼 관리 화면 구성 참고
- 워크스페이스 관리: 테넌트 생성/삭제
- 전체 사용량 모니터링
- 시스템 설정: 전역 모델 정책, 과금
