## Summary

대규모 리팩터링(탭 → 파일 탐색기+콘텐츠 뷰 구조)이 완료된 스킬 관리 화면은 팀 스킬 라이브러리와 관리자 대기열 워크플로우 설계가 탄탄하다. 그러나 **두 개의 독립적인 스킬 관리 뷰(`SkillManagementView` 레거시 vs `SkillsPageView` 신규)가 코드베이스에 공존**하는 구조적 혼란이 최우선 해결 과제이며, 실제 사용자 흐름에서 스킬 추가 기능이 "준비 중" 상태로 막혀 있는 기능 부재가 업무 연속성을 저해한다.

## Part 1: UX Checklist Findings

### Flow Analysis

#### SkillsPageView (신규 — 실제 진입점 /settings/skills)

- Entry: `src/app/settings/skills/page.tsx` → Suspense → `SkillsPageView` → `Tabs[팀 스킬 | 관리]`
- Actions: 팀 스킬 조회/필터/활성화, 슬라이드 패널 열기, 편집·제안·삭제; 관리자: 대기열 검토, 스킬 관리, 카테고리 관리
- Exits: 슬라이드 패널 닫기 → 테이블 복귀
- Issues: "채팅에서 만들기"·"파일에서 가져오기" 버튼이 toast("준비 중")만 발생 — 사용자가 스킬 추가 경로를 찾지 못함

#### SkillManagementView (레거시 — 어느 라우트에서도 사용되지 않음)

- Entry: re-export 래퍼(`src/components/SkillManagementView.tsx`)가 존재하나, 실제 라우트에서 임포트하는 코드가 없음
- Actions: 카탈로그/활성/팀/관리 탭, 스킬 추가(SkillCreateHub) 등 완성된 기능 존재
- Issues: 빈 mock 배열(`mockSkills: []`)로 인해 기능 동작 불가 상태

## Part 2: Scenario-Based Product Review

### S1: 팀원이 처음으로 스킬 라이브러리에서 필요한 스킬을 찾아 활성화한다

- **페르소나**: 에이전트 사용 팀원, 기술 초보~~중급, 주 1~~2회, 여유로운 업무 시간
- **현재 경로**:
  1. `/settings/skills` 진입 → `SkillsPageView` 렌더링 (Suspense 로딩)
  2. "팀 스킬" 탭 자동 선택 → `TeamSkillsTab` → `SkillFilters` + `SkillTable`
  3. 검색 입력창에 키워드 입력 → `filteredSkills` 실시간 갱신
  4. 카테고리/상태/작성자 필터 조합
  5. 원하는 스킬 행 클릭 → `SkillSlidePanel` 오픈 (55% / 45% 분할)
  6. SKILL.md 본문 확인, 버전 이력·제안 이력 Collapsible 확인
  7. `SkillSlidePanelHeader`의 활성화 Switch 토글(아니면 테이블 직접 토글)
  8. toast("활성화되었습니다") 확인
- **마찰점**:
  1. [입력 유형 부적합] 검색창에 X(초기화) 버튼 없음
    - 위치: `SkillFilters.tsx:62-69`
    - 현재: `<Input>` 단독, clearable 없음
    - 문제: 사용자가 검색어를 지우려면 전체 선택 후 Delete 필요
  2. [피드백 부재] 활성화 토글 피드백이 `TeamSkillsTab`의 커스텀 toast — Sonner와 스타일 불일치, 그리고 3초 자동 소멸이 너무 빠름
    - 위치: `TeamSkillsTab.tsx:136-141`
    - 현재: `setTimeout(() => showToast(...), 0)` — setState 내 비동기 처리
    - 문제: 이미 활성화 중인 스킬을 토글하면 왜 비활성화하는지 안내 없음
  3. [위치 비직관] 활성화 상태가 테이블의 오른쪽 끝 Switch에만 있고, 슬라이드 패널 헤더에는 텍스트로만 표시("활성화 중"/"비활성") — 패널에서 직접 토글 불가
    - 위치: `SkillSlidePanelHeader.tsx:104-111`
    - 현재: 텍스트 뱃지만 표시
    - 문제: 사용자가 패널에서 확인 후 활성화하려면 패널을 닫고 테이블 Switch를 찾아야 함
  4. [화면 과밀] 슬라이드 패널 45% 너비에서 파일 탐색기 + 버전 이력 Collapsible + 제안 이력 Collapsible이 모두 세로 스크롤 — 짧은 스킬은 괜찮지만 첨부 파일 많은 스킬은 파악 어려움
    - 위치: `SkillSlidePanel.tsx:456-489`
- **개선안**:
  1. 검색창 clearable X 버튼 추가
    - 현재: Input 단독
    - 제안: `<div className="relative">` + 우측 `<button onClick={() => onSearchChange('')}><X size={14} /></button>`
    - 대상 파일: `src/components/features/skill-management/components/SkillFilters.tsx:62-69`
    - effort: Low
  2. 패널 헤더에 활성화 토글 추가
    - 현재: 텍스트 뱃지만
    - 제안: `<Switch checked={skill.isActivatedByMe} onCheckedChange={onToggleActivation} />` + `onToggleActivation` prop 추가
    - 대상 파일: `SkillSlidePanelHeader.tsx`, `SkillSlidePanel.tsx`
    - effort: Medium
  3. toast 라이브러리 일원화 (Sonner)
    - 현재: `TeamSkillsTab`의 자체 toast 구현
    - 제안: `import { toast } from 'sonner'` 로 교체, `showToast` 헬퍼 제거
    - 대상 파일: `components/TeamSkillsTab.tsx`
    - effort: Low
- **빠진 기능**: 스킬 미리보기(실제 채팅에서 스킬 동작 테스트 — "테스트" 버튼이 준비 중 상태)

### S2: 팀원이 스킬 내용을 개선하여 관리자에게 제안을 제출한다

- **페르소나**: 에이전트 팀원, 기술 중급, 주 1회, 여유롭게
- **현재 경로**:
  1. 스킬 행 클릭 → `SkillSlidePanel` 오픈 (read mode)
