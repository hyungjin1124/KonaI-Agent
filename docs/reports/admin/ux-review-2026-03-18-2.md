### [높음] 작업 버튼의 `aria-label`은 모든 행에서 일반적입니다 — 고유하지 않음
**파일**: `src/components/features/permission-settings/components/RowSecurityLayer.tsx:163–173`, `ColumnMaskingLayer.tsx:131–145`, `RoleDefinitionManager.tsx:338–354`, `OrgRoleMappingManager.tsx:466–483`
**WCAG**: 4.1.2 Name, Role, Value
**설명**: 아이콘만 있는 편집 및 삭제 버튼은 어느 행에 속하든 정적 `aria-label="규칙 편집"` / `aria-label="규칙 삭제"`(또는 "정책 편집" / "역할 편집" 등)을 사용합니다. 화면 읽기 프로그램 사용자가 버튼으로 페이지를 탐색할 때 각 버튼이 어느 행에 작용하는지 구별할 방법이 없는 동일한 버튼 이름을 만납니다.
**수정 방법**: 행의 ID 문자열에서 동적으로 `aria-label`을 구성합니다. 예제:
- `aria-label={${roleLabelMap[rule.role] ?? rule.role} 규칙 편집}`
- `aria-label={${SENSITIVE_CATEGORY_LABELS[policy.category]} 정책 삭제}`
