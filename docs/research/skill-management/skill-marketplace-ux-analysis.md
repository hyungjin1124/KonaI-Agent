# AI 에이전트 스킬 마켓플레이스 UX 비교 분석

> 분석 일자: 2026-03-18  
> 목적: 현재 6개 하드코딩 스킬 → 실제 디렉토리/마켓플레이스 경험으로 확장하기 위한 벤치마크

## 2. 검색/탐색 UX 비교

### 2.1 카테고리 분류 체계

**Anthropic Skills Directory**
- 분류 depth: 1단계 (플랫 구조)
- 접근 방식: 파트너사 브랜드 중심 (Notion, Figma, Atlassian, Canva, Zapier, Stripe, Vercel, Cloudflare)
- 카테고리 대신 MCP 커넥터와 연계된 "기능별 그룹"으로 동작
- 특징: 스킬 수가 적어 카테고리보다 "전체 리스트 스캔"이 효율적

**SkillsMP.com**
- 분류 depth: 1단계, 12개 카테고리
- 카테고리 예시: Development, Data & AI, DevOps, Web App Development, Content Creation 등
- 서브카테고리: 없음 (태그로 보완)
- 특징: AI 시맨틱 검색(`search --ai`)으로 카테고리 한계 보완

**VS Code Extension Marketplace**
- 분류 depth: 1단계, 11개 공식 카테고리
- 카테고리: Programming Languages, Snippets, Linters, Themes, Debuggers, Formatters, Keymaps, SCM Providers, Extension Packs, Language Packs, Other
- 태그 시스템: 무제한 자유 태그 (예: `node`, `python`, `git`)
- 필터 조합: `@category:` + `tag:` + `@sort:` 조합 가능

**Raycast Store**
- 분류 depth: 1단계, 15+ 카테고리
- 카테고리: Design Tools, Developer Tools, Productivity, Project Management, AI, Pomodoro Timer, Time Management, Transcript, Translation, Work From Home 등
- 특징: 카테고리가 "사용 시나리오" 중심으로 설계됨

**Zapier App Directory**
- 분류 depth: 1단계, 기능 카테고리 (CRM, Spreadsheet, Marketing Automation 등)
- 특징: 각 앱 프로필 페이지에 카테고리 태그 노출, 카테고리 클릭 시 관련 앱 리스트로 이동
- 검색: 앱 이름, 카테고리, 트리거/액션 타입으로 필터링

**ChatGPT GPT Store**
- 분류 depth: 1단계, 6개 카테고리
- 카테고리: DALL·E, Writing, Research, Programming, Education, Lifestyle
- 특징: 리더보드(인기/트렌딩) 중심, 에디터 픽 큐레이션

| 평점순 정렬 | ❌ | ❌ | ✅ (1-5별점) | ❌ | ❌ | ❌ |

### 2.3 추천/큐레이션 방식

| 방식 | 적용 플랫폼 | 설명 |
|------|------------|------|
| **에디터 추천 (Staff Picks)** | GPT Store, VS Code, Raycast | 플랫폼 운영팀이 수동 선별 |
| **인기 리더보드** | GPT Store, SkillsMP | 설치 수/사용량 기반 자동 순위 |
| **번들/역할 기반 추천** | antigravity-awesome-skills | "Web Dev → Web Wizard", "Security → Security Engineer" 등 역할별 스킬 세트 추천 |
| **워크플로 기반 추천** | Zapier, antigravity | "이 트리거를 쓰는 사람이 같이 쓴 액션" 형태 |
| **컨텍스트 자동 제안** | ChatGPT Apps, Claude Skills | 대화 맥락에서 관련 스킬/앱 자동 추천 |
| **추천 확장** | VS Code | 워크스페이스 기반 추천 (팀원이 많이 쓰는 것) |

### 3.2 카드 레이아웃 비교

**그리드(Grid) 방식** — Raycast Store, GPT Store, Zapier
- 3~4열 그리드
- 아이콘 강조, 짧은 텍스트
- 시각적 탐색에 유리, 한눈에 많은 항목 노출
- 비개발자 친화적

**리스트(List) 방식** — VS Code (사이드바), SkillsMP
- 1열 세로 리스트
- 아이콘 + 이름 + 설명 + 메타데이터를 한 행에 표시
- 정보 밀도가 높음, 비교가 쉬움
- 개발자 친화적

**하이브리드** — VS Code (웹), Anthropic Skills Directory
- 웹에서는 그리드, 앱 내에서는 리스트
- Anthropic는 커넥터 페이지에서 카드형, 설정에서는 리스트형

## 5. "설치" 버튼 동작 비교

| 플랫폼 | 설치 방식 | 사용자 액션 | 관리자 승인 |
|--------|----------|------------|------------|
| **Anthropic Skills** | ZIP 업로드 또는 GitHub에서 다운로드 후 업로드 | 3단계 (다운로드 → 업로드 → 활성화) | Team/Enterprise: 관리자 프로비저닝 가능 |
| **SkillsMP** | CLI 클론 (`git clone` + 복사) | 터미널 명령어 필요 | ❌ |
| **antigravity** | npx 인스톨러 또는 수동 복사 | 1~2단계 CLI | ❌ |
| **VS Code** | 원클릭 Install 버튼 | 1단계 (클릭) | ❌ (기업 정책으로 제한 가능) |
| **Raycast** | 스토어에서 원클릭 설치 | 1단계 (클릭) | ❌ |
| **Zapier** | 앱 연결 + OAuth 인증 | 2~3단계 (연결 → 인증 → 워크플로 설정) | Enterprise: 관리자 승인 |
| **GPT Store** | "Start Chat" 버튼 | 1단계 (즉시 대화 시작) | Enterprise/Edu: 관리자 토글 |

## 7. 우리 시스템을 위한 전략적 시사점

### 7.2 스케일별 권장 UX 전략

**Phase 1: 20–50개 스킬 (단기)**

이 규모에서는 카테고리 + 토글 방식이 가장 효과적이다. Anthropic Skills Directory의 현재 접근법을 참고하되, 카테고리 태그를 추가한다.

권장 패턴:
- 상단에 검색바 + 카테고리 필터 탭 (3~5개: 전체, 문서, 데이터, 업무도구, 커스텀)
- 카드형 그리드 (3열) — 비개발자도 시각적으로 탐색 가능
- 카드 정보: 아이콘, 이름, 1줄 설명, 제작자, on/off 상태 표시
- "추천" 섹션을 최상단에 배치 (에디터 추천 3~5개)

**Phase 2: 50–200개 스킬 (중기)**

검색과 필터의 중요성이 급격히 증가한다. VS Code의 필터 시스템과 Raycast의 카테고리 UX를 참조한다.

추가 권장:
- 검색 자동완성 + 태그 필터
- "인기순", "최신순", "추천순" 정렬 옵션
- 스킬 상세 페이지 도입 (설명, 요구사항, 관련 스킬)
- "설치됨" vs "탐색" 탭 분리
- 관리자 전용 "조직 추천 스킬" 기능

**Phase 3: 200개+ 스킬 (장기)**

커뮤니티 생태계와 고급 탐색이 필요하다. SkillsMP의 시맨틱 검색과 antigravity의 번들 시스템을 참조한다.

추가 권장:
- AI 시맨틱 검색 ("내 업무와 관련된 스킬 찾기")
- 역할/시나리오 기반 번들 ("마케팅 담당자 필수 스킬", "재무팀 추천 세트")
- 사용자 리뷰/평점 시스템
- "이 스킬을 쓴 사람이 같이 쓴 스킬" 추천
- 커스텀 스킬 제출/심사 파이프라인
- 조직 내부 스킬 vs 마켓플레이스 스킬 구분

### 7.3 권장 카테고리 분류 체계 (한국 기업 맥락)

우리 사용자(한국 기업 도메인 전문가, 비개발자 포함)를 고려하면 "기술 도메인" 보다 "업무 시나리오" 중심 카테고리가 적합하다. Raycast의 시나리오 중심 접근법을 참고한다.

| 카테고리 | 설명 | 예시 스킬 |
|---------|------|----------|
| 📄 문서 작성 | 보고서, 기획서, 제안서 등 문서 생성 | Excel, PPT, Word, PDF 생성 |
| 📊 데이터 분석 | 데이터 정리, 시각화, 인사이트 도출 | 차트 생성, CSV 분석, 대시보드 |
| 🔗 외부 도구 연동 | 기존 업무 도구와의 연결 | Notion, Jira, Slack, Google Drive |
| 🎨 콘텐츠 제작 | 마케팅, 디자인, 미디어 콘텐츠 | Figma 연동, 이미지 생성, 번역 |
| ⚙️ 업무 자동화 | 반복 작업 자동화, 워크플로 | 이메일 자동화, 스케줄링, 양식 처리 |
| 🏢 도메인 전문 | 산업별 특화 스킬 | 법률 문서, 재무 분석, HR 프로세스 |

## 8. 핵심 디자인 원칙 (벤치마크에서 도출)

1. **점진적 공개 (Progressive Disclosure)**: 처음에는 단순한 카드와 토글을 보여주고, 상세 정보는 클릭 시 펼침. Agent Skills 표준의 핵심 설계 원칙이기도 함.

2. **시나리오 중심 분류**: 기술 도메인이 아닌 업무 시나리오로 카테고리를 구성하여 비개발자의 스킬 발견을 돕는다. Raycast Store의 접근법 참조.

3. **신뢰 신호 표시**: 제작자(파트너 vs 커뮤니티 vs 커스텀) 구분을 명확히 하고, 사용 현황/평점 같은 "소셜 프루프"를 카드에 포함한다. SkillsMP의 GitHub stars, VS Code의 설치 수/별점이 좋은 사례.

4. **원클릭 설치에 가까운 경험**: 현재 Anthropic의 "다운로드→업로드→활성화" 3단계를 줄여, "마켓플레이스에서 클릭 → 즉시 활성화"에 가까운 경험을 제공한다. VS Code와 Raycast가 설정한 표준.

5. **관리자 거버넌스 레이어**: Anthropic의 Team/Enterprise 관리 기능처럼, 조직 관리자가 스킬을 프로비저닝하고, 접근 권한을 제어하며, 사용 현황을 감사할 수 있어야 한다.

6. **한국어 우선 UX**: 카테고리명, 스킬 설명, 검색 키워드 모두 한국어로 제공. 필요시 영문 원본 병기.
