## 2. 스코프 모델

### 팀 공유 드라이브

스킬 화면은 **팀이 공유하는 드라이브**와 같다. 누구나 올릴 수 있고, 올라간 스킬은 팀 전체에 즉시 보인다.

| 항목 | 내용 |
|------|------|
| **공유 범위** | 팀 단위. 생성·수정한 스킬은 즉시 팀 전체에 공유됨. 승인 절차 없음 |
| **탐색 범위** | 내 팀 스킬만 열람 가능. 다른 팀 스킬은 볼 수 없음 |
| **팀 소속** | 1인 1팀. 다중 팀 소속 없음 |

### 활성화 모델

팀 스킬 중 **내가 사용할 스킬만 활성화**한다. 활성화해도 사본이 생기지 않고, 원본(또는 내 수정본)을 그대로 참조한다.

| 동작 | 설명 | 결과 |
|------|------|------|
| **활성화** | 팀 스킬을 내 채팅에서 사용하겠다고 선택 | 에이전트가 해당 스킬을 호출 가능 |
| **비활성화** | 내 채팅에서 더 이상 사용하지 않음 | 에이전트가 호출하지 않음. 팀에서 사라지지 않음 |

### 개인 수정본

팀 스킬을 수정하고 싶으면 **편집을 시작하는 순간 개인 수정본이 자동 생성**된다. 수정본은 팀에 즉시 공유되며, 별도 승인 절차 없이 내 채팅에 바로 적용된다.

```
팀 스킬 (원본)
    │
    └─ [편집] → 개인 수정본 자동 생성
                    │
                    ├─ 수정 (인라인 / 채팅)
                    ├─ [저장] → 내 채팅에 즉시 적용 + 팀에 공유
                    │
                    ├─ 계속 수정 가능 (반복)
                    └─ 원본 복구 → 수정본 폐기, 원본으로 복귀
```

**핵심 원칙:**
- 같은 원본 스킬에 대해 **사용자마다 각자의 수정본**을 가질 수 있다
- 수정본은 팀 전체에 보인다 — 테이블에서 누가 어떤 수정본을 가지고 있는지 확인 가능
- 수정본이 있는 사용자의 채팅에서는 원본 대신 수정본이 자동 적용
- 수정본이 없는 사용자의 채팅에서는 원본이 그대로 사용됨

*[설계 변경 (v6): (1) 수정본이 개인에게만 보이던 것을 팀에 공유로 변경 — 공유 드라이브 원칙. (2) 개선 제안 제출 → 관리자 승인 프로세스 제거 — 수정하면 바로 반영. (3) 삭제/폐기 기능 제거 — 올라간 것은 그냥 둠. 문제 생기면 나중에 디벨롭.]*

### 3.2 스킬 상세 — 슬라이드 패널

테이블 행 클릭 시 우측에서 슬라이드로 열리는 상세 패널.

#### 헤더

| 요소 | 설명 |
|------|------|
| 스킬 이름 | 제목 |
| 설명 (Description) | 스킬이 무엇을 하는지 한 줄 설명 |
| 카테고리 | 태그 |
| 메타 정보 | 작성자, 버전, 사용횟수, 출처(직접 생성/외부 가져오기), 생성일, 최종 수정일 |
| 상태 표시 | "활성화 중" 또는 "비활성" (텍스트만, 토글은 테이블에서) |
| 액션 버튼 | 아래 참조 |
| 전체 확장 | [↗] 버튼 → 전체 페이지로 전환 (편집 작업 시 넓은 공간 확보) |

#### 패널 액션

패널은 항상 **"내 현재 버전"**을 표시한다. 수정본이 없으면 원본, 수정본이 있으면 수정본이 표시된다.

**읽기 모드 — 수정본 없음:**

| 직접 노출 | "..." 메뉴 |
|----------|-----------|
| [채팅에서 편집] | 직접 편집 |

**읽기 모드 — 수정본 있음:**

| 직접 노출 | "..." 메뉴 |
|----------|-----------|
| [채팅에서 편집] | 직접 편집, 원본 복구 |

수정본이 있는 읽기 모드에서는 콘텐츠 영역 상단에 **[diff 보기]** 버튼을 제공한다. 클릭하면 원본과 수정본의 side-by-side diff로 전환되고, 다시 클릭하면 수정본 단독 뷰로 복귀한다.

**편집 모드:**

| 직접 노출 | "..." 메뉴 |
|----------|-----------|
| [취소], [저장] | — (없음) |

편집 모드에서도 콘텐츠 영역 상단에 **[diff 보기]** 버튼을 제공한다. 원본 대비 현재 편집 내용을 side-by-side로 확인하고 돌아와서 편집을 계속할 수 있다.

**액션 상세:**
- **[채팅에서 편집]**: 주 편집 경로. AI 채팅으로 이동하여 스킬 컨텍스트를 로드한 상태에서 대화형으로 편집
- **직접 편집** ("..." 내): 보조 편집 경로. 수정본이 없으면 자동 생성 후 편집 모드 진입, 있으면 기존 수정본 열기. 오타 수정, 파라미터 값 변경 등 경미한 수정에 적합
- **원본 복구** ("..." 내): 수정본을 폐기하고 원본으로 복귀. 내 채팅도 원본으로 자동 전환
- **[취소]**: 미저장 변경이 있으면 확인 모달 표시. 확인 시 편집 모드 종료, 이전 읽기 상태로 복귀
- **[저장]**: 편집 내용 저장 → 내 채팅에 즉시 적용 + 팀에 공유 → 편집 모드 종료 → 수정본 읽기 전용 뷰로 복귀
- **미저장 이탈 방지**: 편집 모드에서 패널 닫기/다른 행 클릭 시도 시에도 확인 모달 표시

*[설계 변경 (v6): (1) 작성자/비작성자 분기 제거 — 삭제 기능이 없으므로 모든 사용자에게 동일한 액션. (2) [개선 제안 제출] 제거 — 승인 프로세스 없음. (3) 저장 시 팀에 즉시 공유.]*

#### 본문 (파일 탐색기 + 콘텐츠 뷰)

헤더 아래 본문은 **파일 목록 → 콘텐츠 영역 → 버전 이력** 순으로 구성된다. 스킬은 파일 패키지이므로, 파일 목록에서 파일을 선택하면 해당 파일의 내용이 콘텐츠 영역에 표시되는 구조를 사용한다.

**A. 파일 목록**

```
● SKILL.md                        ← 기본 선택 (강조 표시)
  scripts/extract_data.py
  references/report-template.md
  assets/logo.png
```

- 스킬 패키지에 포함된 모든 파일을 목록으로 표시
- SKILL.md가 기본 선택 상태. 패널을 열면 자동으로 SKILL.md 내용이 콘텐츠 영역에 표시
- 다른 파일 클릭 시 콘텐츠 영역이 해당 파일 내용으로 전환
- 단일 파일 스킬: SKILL.md만 표시 (파일 목록 영역이 최소화)

**B. 콘텐츠 영역**

파일 목록에서 선택한 파일의 내용을 표시하는 영역.

| 선택 파일 | 표시 내용 |
|-----------|----------|
| SKILL.md (기본) | 파일 내용 전문 |
| 텍스트 파일 (.md, .txt, .csv) | 파일 내용 전문 |
| 스크립트 (.py, .js, .sh) | 코드 하이라이팅 적용 |
| 바이너리 (.png, .pdf 등) | 미리보기 (이미지: 렌더링, PDF: 뷰어) |

원본 상태에서는 **읽기 전용**. [편집] 버튼을 누르면 패널 전체가 편집 모드로 전환되며, 파일 타입에 따라 편집 방식이 달라진다:

| 파일 유형 | 편집 모드 동작 |
|-----------|--------------|
| 텍스트 (.md, .txt, .csv) | 콘텐츠 영역에서 바로 인라인 편집 |
| 스크립트 (.py, .js, .sh) | 콘텐츠 영역 상단에 [채팅에서 수정] 버튼 표시 |
| 바이너리 (.png, .pdf 등) | 콘텐츠 영역 상단에 [파일 교체] 버튼 표시 |

파일 간 이동: 편집 모드에서 파일 목록의 다른 파일을 클릭하면, 현재 파일의 편집 내용이 유지된 채 선택 파일로 전환. 각 파일의 편집 상태는 독립적으로 관리.

**C. 버전 이력 + AI 변경 요약** (기본 접힘)

각 버전마다 **에이전트가 생성한 변경 요약**을 표시한다. raw diff 대신 자연어로 "무엇이 어떻게 바뀌었는지"를 설명하여, 스킬 내용(영어·장문)을 직접 읽지 않아도 변경 내용을 파악할 수 있게 한다.

```
▼ 버전 이력

  v3 — 03-22 홍길동
  ┌──────────────────────────────────────────────────┐
  │ 🤖 변경 요약                                      │
  │ "데이터 검증 단계가 추가되었습니다. 입력 파일에서    │
  │  빈 셀이 발견되면 기본값(0)으로 채우는 로직이        │
  │  포함되었고, 출력 형식이 표에서 차트로 변경되었습니다.│
  │  트리거 조건에 '분기 보고서'가 추가되었습니다."       │
  └──────────────────────────────────────────────────┘
  [원문 비교 보기]

  v2 — 03-15 홍길동
  ┌──────────────────────────────────────────────────┐
  │ 🤖 변경 요약                                      │
  │ "결과물에 전월 대비 증감률 컬럼이 추가되었습니다.     │
  │  데이터 소스가 CSV에서 Excel(.xlsx)도 지원하도록     │
  │  확장되었습니다."                                    │
  └──────────────────────────────────────────────────┘
  [원문 비교 보기]

  v1 — 03-01 홍길동 (최초 생성)
```

| 항목 | 설명 |
|------|------|
| 버전 목록 | 수정일, 수정자, AI 변경 요약 |
| AI 변경 요약 | 에이전트가 이전 버전과 비교하여 자연어로 생성한 변경 내용 설명. 한국어로 제공 |
| [원문 비교 보기] | 클릭 시 side-by-side diff 표시. 원문을 직접 확인하고 싶은 사용자를 위한 선택적 기능. 패널 폭이 좁으면 unified diff로 폴백 |
| 버전 복원 | 이전 버전으로 되돌리기 — 원본 작성자만 가능 |

*[설계 변경 (v6): raw diff를 기본 뷰로 사용하지 않음. "사람들이 영어 + 장문 diff를 읽지 않을 것"이라는 리더 피드백 반영. 에이전트가 버전별로 어떤 부분이 바뀌었는지 인사이트를 한국어로 제공하고, 원문 diff는 선택적으로 접근.]*

### 3.3 편집 모드

"..." 메뉴의 [직접 편집]을 누르면 **패널 전체가 편집 모드로 전환**된다. 주 편집 경로는 [채팅에서 편집]이며, 직접 편집은 오타 수정 등 경미한 변경용 보조 경로이다.

#### 편집 모드 패널 구성

| 영역 | 내용 |
|------|------|
| 상단 바 | "편집 중" 라벨, [diff 보기] 버튼, [취소] [저장] |
| 본문 | 파일 탐색기 + 콘텐츠 뷰 |

편집 모드에서는 "..." 메뉴가 없다. 수정본 폐기(원본 복구)가 필요하면 [취소]로 읽기 모드에 복귀한 후 "..." 메뉴에서 접근한다.

**저장 후 흐름:**
- 저장 → 내 채팅에 즉시 적용 + 팀에 공유 → 편집 모드 종료 → 수정본 읽기 전용 뷰로 복귀
- 버전 이력에 새 버전 추가 + AI 변경 요약 자동 생성

**취소 흐름:**
- 미저장 변경이 있으면 "저장하지 않은 변경이 있습니다" 확인 모달 → 확인 시 편집 모드 종료, 이전 읽기 상태로 복귀

## 4. 스킬 추가 경로

스킬을 팀에 등록하는 경로는 2가지이다. 등록 즉시 팀에 공유되며, 생성자는 자동 활성화된다.

| 경로 | 진입점 | 설명 | 근거 |
|------|--------|------|------|
| 채팅에서 만들기 | [+ 추가] → "채팅에서 만들기" | AI 채팅으로 이동. 스킬 생성 프롬프트가 자동 입력되어 대화형으로 스킬을 설계 | Anthropic skill-creator, Manus conversation-to-skill, Relevance AI "Invent" |
| 파일에서 가져오기 | [+ 추가] → "파일에서 가져오기" | 파일 업로드 모달에서 SKILL.md 또는 .zip 패키지 업로드 | Manus .skill 업로드, Claude.ai Settings > Skills ZIP upload |

### 4.1 진입점 — [+ 추가] 버튼

팀 스킬 테이블 상단의 **[+ 추가]** 버튼을 클릭하면 드롭다운이 열리며 2개 옵션을 표시한다.

```
┌──────────────────────────┐
│  + 추가 ▼                │
├──────────────────────────┤
│  💬 채팅에서 만들기       │
│  📁 파일에서 가져오기     │
└──────────────────────────┘
```

### 4.2 채팅에서 만들기

#### 진입 흐름

```
[+ 추가] → "채팅에서 만들기"
    │
    ▼
AI 채팅 뷰 (새 세션)
    │
    ├─ 시스템: 스킬 생성 모드 컨텍스트 로드
    ├─ 입력창: 프롬프트 템플릿 자동 입력 (사용자 편집 가능, 전송 전 상태)
    │
    ▼
사용자가 프롬프트 확인/편집 후 전송
    │
    ▼
에이전트: Intent 확인 → 상세화 질문 → SKILL.md 초안 생성 → 확인 요청
    │
    ▼
사용자: 검토·수정 → 승인
    │
    ▼
스킬 등록 (팀에 즉시 공유, 생성자 자동 활성화)
```

#### 자동 입력 프롬프트

채팅 입력창에 아래 템플릿이 미리 채워진 상태로 표시된다. 사용자는 `{ }` 부분을 자신의 내용으로 교체한 후 전송한다.

```
새로운 스킬을 만들고 싶습니다.

**목적**: {이 스킬이 무엇을 하는지 설명해주세요}
**트리거 상황**: {언제 이 스킬이 사용되어야 하는지 — 사용자가 어떤 요청을 했을 때?}
**결과물 형식**: {스킬 실행 결과의 형태 — 파일, 텍스트, 데이터 등}
```

#### 에이전트의 대화형 생성

프롬프트를 수신한 에이전트는 부족한 정보를 추가 질문한 후(엣지 케이스, 입출력 형식, 성공 기준 등), SKILL.md 초안을 생성하여 채팅 내에서 미리보기로 제시한다. 사용자가 승인하면 팀에 등록된다.

| 등록 시 동작 | 설명 |
|-------------|------|
| SKILL.md 저장 | 에이전트가 생성한 최종 SKILL.md를 서버에 저장 |
| 팀 공유 | 팀 스킬 테이블에 즉시 추가 |
| 생성자 자동 활성화 | 생성자의 채팅에서 즉시 사용 가능 |
| 메타데이터 설정 | 작성자, 생성일, 출처("채팅 생성"), 버전 1.0 |

### 4.3 파일에서 가져오기

#### 파일 업로드 모달

```
┌───────────────────────────────────────────────────────┐
│  파일에서 가져오기                                [✕]  │
├───────────────────────────────────────────────────────┤
│                                                       │
│  ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐ │
│  │                                                 │ │
│  │   📁 파일을 드래그하거나 클릭하여 선택하세요     │ │
│  │                                                 │ │
│  │   지원 형식: SKILL.md (단일 파일), .zip (패키지)  │ │
│  │                                                 │ │
│  └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘ │
│                                                       │
│                                     [취소]  [등록]     │
└───────────────────────────────────────────────────────┘
```

#### 지원 파일 형식

| 형식 | 처리 |
|------|------|
| **SKILL.md** (단일 파일) | 파일을 직접 파싱하여 등록 |
| **.zip** (패키지) | 압축 해제 후 SKILL.md 존재 여부 확인 → 전체 패키지 등록 |

#### 검증 규칙

**필수 검증 (통과 못하면 등록 불가):**

| 규칙 | 실패 시 메시지 |
|------|---------------|
| SKILL.md 존재 | "SKILL.md 파일을 찾을 수 없습니다" |
| 프론트매터 파싱 가능 | "YAML 프론트매터를 파싱할 수 없습니다" |
| name 필드 존재 | "`name` 필드가 필요합니다" |
| description 필드 존재 | "`description` 필드가 필요합니다" |
| 이름 중복 없음 | "'{name}' 이름의 스킬이 이미 존재합니다" |

**경고 검증 (경고 표시, 등록은 가능):**

| 규칙 | 경고 메시지 |
|------|-----------|
| description 1024자 초과 | "설명이 권장 길이(1024자)를 초과합니다" |
| 본문 500줄 초과 | "본문이 500줄을 초과합니다. 보조 파일로 분리를 권장합니다" |

검증을 통과하면 모달에 미리보기(이름, 설명, 포함 파일 목록)가 표시되고, [등록] 클릭 시 팀에 즉시 등록된다.

## 6. 주요 인터랙션 패턴

### 6.1 활성화 토글

활성화 토글은 **테이블에서만** 제공. 슬라이드 패널에서는 현재 상태 텍스트만 표시.

| 상태 | 동작 | 영향 범위 |
|------|------|----------|
| 활성 → 비활성 | 에이전트가 해당 스킬을 호출하지 않음 | 해당 사용자의 채팅 세션만 |
| 비활성 → 활성 | 에이전트가 다시 호출 가능 | 해당 사용자의 채팅 세션만 |

토글 시 행이 활성화/비활성 그룹 간 이동하며, 이동 자체가 시각적 피드백이 된다.

### 6.2 편집 모드

원본은 읽기 전용. "..." 메뉴의 [직접 편집]을 누르면 패널 전체가 편집 모드로 전환된다. 주 편집 경로는 [채팅에서 편집]이며, 직접 편집은 보조 경로이다.

**[diff 보기] 버튼** — 콘텐츠 영역 상단에 위치. 클릭하면 원본 대비 현재 편집 내용을 side-by-side diff로 표시 (읽기 전용). 다시 클릭하면 편집 뷰로 복귀. 패널 폭이 좁으면 unified diff로 폴백.

**액션**: [취소]와 [저장]을 직접 노출. "..." 메뉴 없음.

### 6.3 검색·필터

| 위치 | 검색 범위 | 동작 |
|------|----------|------|
| 팀 스킬 테이블 | 팀 전체 스킬 | 이름, 설명, 작성자, 카테고리 기준 실시간 필터링 |

### 6.4 버전 비교 — AI 변경 요약

버전 이력에서 각 버전을 확인할 때 **에이전트가 생성한 자연어 변경 요약**이 기본으로 표시된다.

| 항목 | 설명 |
|------|------|
| AI 변경 요약 생성 시점 | 스킬 저장 시 자동으로 이전 버전과 비교하여 생성 |
| 언어 | 한국어 (사용자 설정 언어를 따름) |
| 내용 | 추가된 기능, 변경된 로직, 수정된 트리거 조건, 형식 변경 등을 구체적으로 설명 |
| 원문 비교 | [원문 비교 보기] 버튼으로 side-by-side diff 접근 가능 (선택적) |

*[설계 근거: 리더 피드백 — "diff 방식으로 보여줘도 사람들이 읽지 않을 것 (영어 + 장문)". 에이전트가 변경 사항을 분석하고 인사이트를 자연어로 제공하여 비개발자도 버전 간 차이를 쉽게 이해할 수 있도록 함.]*

## 7. 상태별 화면 변화

### 7.1 팀 스킬 테이블 — 빈 상태

```
│                                                             │
│          아직 팀에 등록된 스킬이 없습니다                      │

```

### 7.2 패널 미선택 상태

테이블에서 아직 스킬을 클릭하지 않았을 때. 테이블이 전체 폭으로 표시된다.

### 7.3 수정본 존재 시 테이블 표시

수정본이 있는 스킬은 테이블에서 "수정본" 뱃지로 표시. 해당 행 클릭 시 패널에서 수정본 내용이 표시된다.

## 8. 설계 근거 요약

| 설계 결정 | 채택 근거 | 참조 |
