Phase 2
  • 🏠
    KonaI-Agent
    AI 에이전트 엔터프라이즈 플랫폼
    • 📊
      홈/대시보드
      의사결정 진입점
      전사 직원의 의사결정 진입점. AI 인사이트와 KPI를 한눈에 파악. 홈과 대시보드를 단일 페이지 탭으로 통합.
      • 🤖
        AI 인사이트
        기본 탭
        AI가 자동 발견한 이상 신호, 추세 변화, 기회를 우선순위순 표시. ThoughtSpot AI Highlights 패턴. Level 1~3 통합.
      • 📈
        KPI 대시보드
        현재값 + 트렌드
        조직 핵심 성과 지표 모니터링. 현재값, 변화율, 트렌드 차트 제공.
      • 🎨
        커스텀 대시보드
        사용자/팀 생성
        사용자/팀이 만든 대시보드 목록 + 새 대시보드 생성. AI 채팅 결과 저장 도착점. Databricks Genie→Dashboard 패턴.
      • 🏢
        부서별 성과
        Phase 2
        부서 구조 데이터가 없는 프로토타입 단계에서 제외.
    • 💬
      AI 채팅
      중심 허브 · 개발 중
      이미 개발 중. 다른 메뉴와의 연결점만 본 문서에서 정의. 모든 메뉴의 중심 허브 역할.
      • 대화 인터페이스
        자연어 질의 → AI 분석 → 결과 제공
      • Artifact 패널
        에이전트 생성 결과물 표시 · 스킬 정의 확인/수정
      • 스킬 생성
        대화 기반
        채팅에서 "이걸 반복 작업으로 만들자" → 스킬 생성. Claude Code SKILL.md 패턴.
    • ⚡
      스킬
      업무 자동화 도구 허브
      AI 에이전트가 호출하는 업무 자동화 도구를 탐색·관리하는 중앙 허브. 단일 목록 뷰 + 필터 구조. 생성은 AI 채팅에서.
      • 📋
        스킬 목록
        내 스킬 / 전체 필터
        단일 목록에서 "내 스킬 / 전체" 필터로 전환. 활성 사용자 수 직접 표시. 프로토타입 단계에서 탭 분리 불필요.
      • 편집 · 공유 · 삭제
        기존 스킬의 편집(채팅 이동), 공유, 삭제 관리
      • 스킬 범위
        MCP · API · 프롬프트 · 워크플로우
        포함: MCP 도구, API 커넥터, 프롬프트 템플릿, 워크플로우. 미포함: 에이전트(주체), 데이터 소스(데이터 메뉴).
    • 🗄️
      데이터
      데이터 거버넌스 허브
      데이터 담당자 전용. 에이전트가 올바른 데이터에 올바른 권한으로 접근하도록 설정하는 "백스테이지". OpenAI Frontier Business Context + Enterprise Security.
      • 📑
        뷰 테이블
        메타데이터 · 접근 제어
        ERP 등 소스 DB에서 에이전트가 쿼리할 테이블 목록 탐색, 메타데이터 관리, 개별 접근 제어. Snowflake Catalog Explorer 패턴.
      • 🔗
        온톨로지
        읽기 + 간단 편집
        테이블·컬럼·비즈니스 개념 간 의미 관계 정의. 시맨틱 레이어. 프로토타입: 읽기 전용 시각화 + 간단한 편집. 풀 에디터/AI 자동 생성은 Phase 2.
      • 🔒
        접근 정책
        테이블/행/컬럼 수준
        역할별 테이블/컬럼/행 수준 접근 권한 중앙 관리. 데이터 담당자가 설정. 관리자 메뉴에서는 요약만 표시. Snowflake RLS 패턴.
      • 📝
        감사 로그
        데이터 접근 이력
        데이터 접근 이력만 추적. 누가 어떤 테이블을 언제 조회/수정했는지. 관리자 감사 로그와 범위 구분됨.
    • ⚙️
      관리자
      엔터프라이즈 통제 허브
      사용자·권한·감사·사용량·AI 거버넌스를 통해 엔터프라이즈급 통제를 실현. 3개 카테고리 + Platform Admin 전용 영역.
      • 🔑
        접근 제어
        누가 무엇에 접근?
        • 사용자 관리
          사용자 계정 생성, 역할 할당, 비활성화
        • 권한 관리
          역할 정의, 기능별·데이터별 접근 권한 매트릭스. RBAC 기반.
      • 📡
        모니터링
        무슨 일이 일어났나?
        • 감사 로그
          플랫폼 전체
          플랫폼 전체 활동 로그. 로그인, 권한 변경, AI 사용 등. 데이터 감사 로그보다 넓은 범위.
        • 사용량
          AI 사용량, API 호출, 토큰 소비, 비용 추적. OpenAI Usage Dashboard 패턴.
      • 🛡️
        AI 정책
        AI 행동 제약
        • AI 거버넌스
          AI 가드레일 설정, 콘텐츠 필터, 모델 접근 제어, 데이터 정책 적용 현황. Copilot Studio DLP, ServiceNow AI Control Tower 패턴.
      • 🏗️
        Platform Admin
        전용 · Phase 2
        • 테넌트 관리
          고객사(테넌트) 생성, 설정, 격리 관리. 멀티테넌트 SaaS 대비.
        • 전체 사용량
          전체 테넌트 통합 사용량, 시스템 리소스 모니터링.
        • 시스템 설정
          모델 배포, API 키 관리, 시스템 전역 설정.

🔀 메뉴 간 연결점

채팅 → 대시보드
채팅 결과를 대시보드 위젯으로 저장. "대시보드에 저장" 버튼. ThoughtSpot Pin to Liveboard 패턴.
대시보드 → 채팅
KPI/인사이트 클릭 → 채팅에서 심층 분석. "AI로 분석하기" 버튼.
채팅 ↔ 스킬
채팅 중 @멘션 또는 자동 트리거로 스킬 호출. 결과가 채팅에 표시.
스킬 → 채팅
스킬 상세에서 "채팅에서 실행". 스킬 테스트/실행 진입점.
데이터 → 채팅
에이전트가 온톨로지 + 접근 정책 참조하여 자연어 질의 이해. 시스템 레벨 연결.
관리자 → 전체
RBAC 정책이 모든 메뉴의 접근 권한 제어. 시스템 레벨 연결.
AI 거버넌스 → 접근 정책
AI 거버넌스에서 데이터 정책 적용 현황 요약 → 데이터 메뉴로 딥링크.
데이터 정책 → 대시보드
접근 정책(RLS)이 대시보드 위젯 표시에 자동 적용. 시스템 레벨.
스킬 → 대시보드 (선택)
스킬 실행 결과를 대시보드 위젯으로 추가. 프로토 포함 여부 미결.
스킬 ↔ 데이터 (선택)
스킬이 사용하는 데이터 소스 표시 / 데이터에서 관련 스킬 링크. 프로토 포함 여부 미결.
